# CodeRPG Backend

## Regras de Commit
Para implementar qualquer feature crie uma branch a partir da principal(garanta que está atualizada para não conflitar) e faça suas alterações. Confira que o sistema inteiro está funcionando
como antes e abra um Pull Request assinando alguém como Reviewer, a pessoa fará o review e vai mergear suas alterações se estiver tudo certo.
